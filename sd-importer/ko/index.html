SD Importer

SD 카드 사진을 촬영일별 폴더로 안전하게 정리.

SD Importer는 카메라 SD 카드의 사진과 동영상을 촬영일별 폴더로 복사하는 앱입니다. 복사한 파일은 한 바이트씩 대조하며, SD 카드의 파일은 직접 선택하지 않는 한 지워지지 않습니다.

무료로 사용할 수 있습니다. 마음에 드셨다면 팁으로 개발을 응원해 주세요.

  • 사진의 촬영 일시(EXIF)와 동영상의 생성 일시로 분류
  • yyyy/yyyy-MM-dd 등 자유로운 폴더 이름
  • 내용까지 대조하는 복사, 이미 가져온 파일 자동 건너뛰기, 중단 후 이어서 복사
  • 중복 파일 검사와 나란히 비교
  • 메뉴 막대 진행 표시, 완료 알림, 기록
  • RAW, HEIC, 동영상 지원
